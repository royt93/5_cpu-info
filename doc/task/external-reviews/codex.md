## 3. Feature mới nên làm

- **P0 — Dashboard realtime có biểu đồ lịch sử:** CPU từng core/load, RAM, nhiệt độ, pin và thermal-throttling trong 1/5/15 phút; đây là gap lớn so với CPU Monitor và Device Info HW, không trùng floating overlay đã có roadmap.
- **P0 — Thermal status & throttling diagnostics:** đọc `PowerManager.currentThermalStatus`, thermal headroom (khi hỗ trợ), thermal zones và tương quan xung CPU; cảnh báo khi máy đang throttle thay vì chỉ liệt kê nhiệt độ.
- **P1 — USB/OTG và Bluetooth capability inspector:** liệt kê USB device/interface, USB-C role, Bluetooth version/profile/codec khả dụng; giúp cạnh tranh với AIDA64/Device Info HW ở nhóm kiểm tra phần cứng ngoại vi.
- **P1 — Security posture:** patch level, Verified Boot state, bootloader/root indicators, hardware-backed Keystore/StrongBox, SELinux và encryption; trình bày dạng checklist, không tuyên bố tuyệt đối “an toàn/không an toàn”.
- **P1 — App permission & SDK inventory:** lọc app theo dangerous permission, target SDK, installer source, debuggable/signature và native ABI; tận dụng sẵn màn Applications nhưng phải thiết kế đúng package-visibility policy.
- **P2 — Storage/RAM/CPU benchmark nhẹ có baseline:** đo tuần tự/random I/O trong cache riêng và benchmark nén/hash ngắn, có cooldown và cảnh báo nhiệt; bổ sung số liệu thực nghiệm mà CPU-Z/AIDA64 thiên về metadata chưa mạnh.

## 4. Ý tưởng tính năng độc quyền (unique selling point)

- **P0 — “Device Truth Score”:** đối chiếu thông tin SoC từ native `cpuinfo`, Android `Build`, ABI, core topology, GPU/Vulkan và camera metadata để phát hiện firmware giả model/spec hoặc máy refurb khai sai; xuất bằng chứng từng mismatch thay vì một điểm số mơ hồ.
- **P0 — Throttling Fingerprint:** chạy workload ngắn có kiểm soát, ghi xung từng cluster + thermal status + pin, rồi tạo “đường cong chịu tải” có thể so trước/sau khi thay pin, update ROM hoặc thay keo tản nhiệt; mở lịch sử dài hạn cho VIP.
- **P1 — Hardware Diff / Before–After Snapshot:** ký và lưu snapshot cấu hình, sau OTA/repair tự highlight phần nào đổi (security patch, codec, camera ID, sensor vendor, DRM level, CPU governor); share diff dạng JSON/text đã có nền tảng exporter.
- **P1 — Privacy-preserving Fleet Compare:** tạo fingerprint đã làm mờ identifier và so thiết bị với cùng model/SoC để báo percentile nhiệt, xung, RAM khả dụng, DRM/camera bất thường; opt-in rõ ràng, không gửi GAID/serial.
- **P2 — “Can My Device?” rule engine:** từ capability thực tế (codec profile/level, Widevine/HDCP, HDR, Vulkan extension, RAM) trả lời các câu cụ thể như “phát Netflix HD?”, “quay RAW?”, “chạy game Vulkan?”; rule pack cập nhật từ xa, bản phân tích nâng cao dành cho VIP.
