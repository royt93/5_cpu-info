# Epic 3 — Feature mới (gap vs competitor)

> `doc/quick_win.md` đã cover: Camera, Display/refresh rate, Media codec, DRM/Widevine, Export report, Network info, Battery health, Floating overlay. **Không lặp lại các mục đó** — epic này chỉ chứa gap MỚI phát hiện qua review, so với competitor CPU-Z, AIDA64, Device Info HW, CPU Monitor.

| # | Feature | Mô tả | Effort | Giá trị | Nguồn |
|---|---|---|---|---|---|
| ✅F01 | Realtime dashboard có lịch sử | **Đã xong (2026-09-01)** — tab mới `feat/infor/dashboard` (`FrmDashboard`/`VMDashboard`), vị trí 15 trong ViewPager Hardware. 3 biểu đồ line chart: CPU utilization trung bình (%, tính từ `current/max` mỗi core qua `ObservableCpuData`), RAM used (%, qua `ObservableRamData`), battery temp (°C, qua `ObservableTemperatureData`). Rolling buffer 15 phút (`HistoryBuffer`, evict theo tuổi) — chart tự động chứa cả 3 mốc 1/5/15 phút, **không làm UI toggle riêng**: dựa vào pinch-zoom/pan built-in của thư viện chart thay vì tự dựng window picker (đơn giản hoá có chủ đích, xem library choice bên dưới). **Library**: `MPAndroidChart` (JitPack, Java thuần) thay vì Vico — Vico là Compose-only, build bằng Kotlin hiện đại (rủi ro đúng loại xung đột metadata mà `build.gradle.kts` `force()` block đã ghi chú; đã research trước khi chọn). Verify: `HistoryBufferTest` (4 test) + `VMDashboardTest` (5 test) unit, `assembleDevDebug`/`lintDevDebug` xanh với dependency mới. **Không có instrumented test cho tab này** — điều hướng vào tab kích hoạt lỗi teardown ở tầng test harness (`ActivityScenario` "Cannot run onActivity since Activity has been destroyed already"), xác nhận qua logcat KHÔNG phải app crash thật (process exit code 0, không có FATAL EXCEPTION) — nghi vấn `composeRule.waitForIdle()` không bao giờ "settle" trước 1 ViewModel tick liên tục mỗi giây; đã thử bỏ hết assertion, vẫn lỗi y hệt → quyết định bỏ test thay vì để đỏ vĩnh viễn, dựa vào unit test + build xanh làm bằng chứng chính | L (2-3d) | 🌟🌟🌟 | Codex |

Dùng `libcpuinfo` nhóm core theo cluster, hiển thị microarchitecture + xung min/max từng cụm — đúng cách CPU-Z/Device Info HW làm. **Trùng hướng với U06 (Epic 4)** — nên làm chung 1 task, U06 là bản mở rộng sâu hơn (thêm cache hierarchy) | M (1d) | 🌟🌟🌟 | Gemini CLI |
